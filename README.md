# 雨霖铃 FPGA 多媒体课件

基于安路 HX4S20C / EG4S20BG256 和 TD 5.6.2 的 HDMI 多媒体播放工程。FPGA 独立完成 TF 卡 FAT32 文件扫描、BMP 解析、SDRAM 双帧缓存、1280×720 HDMI 输出、WAV 音频播放、按键交互、字幕、重点图层、转场、亮度和对比度调节以及音频可视化。

GitHub 仓库保存源码、TD 工程、验证脚本和说明文档；原始图片、TF 卡图片、音频及第三方比赛资料保存在本地素材目录，不随代码仓库上传。

TF 卡根目录只放 `TF卡_图片` 和 `TF卡_音频` 里面的 24 个文件，不要把这些文件夹本身复制进卡里。

## 工程入口与构建

- 工程文件：`FPGA_project/src/td_project/func1.al`
- 目标器件：`EG4S20BG256`
- 开发工具：Anlogic TD 5.6.2

如果 TD 已经打开旧工程，请先关闭且不要保存旧配置，再重新打开当前工程。进入 **Read Design** 后重新综合、布局布线并生成 bit。工程的 Route 设置为：

- `effort=high`
- `opt_timing=high`
- `fix_hold=off`

关闭 Route 自动 hold 修正可避免 TD 5.6.2 在 HDMI lane 异步复位入口处异常退出。lane 的异步复位入口通过独立时序例外处理，lane 数据路径仍参与时序检查。

也可以运行工程根目录下的 `01_build.cmd` 或 `02_open_td.cmd`。

## 功能与操作

- KEY1：切换自动轮播/手动模式；自动模式等待当前音频播放结束后换页。
- KEY2：短按下一页，长按返回上一页。
- KEY3：短按调节一档；长按切换亮度/对比度。
- KEY4：复位。
- 最右两位数码管：手动模式显示页码，自动模式显示小写 `on`。
- 1280×720 HDMI 输出，BMP 支持不同输入分辨率并在 FPGA 内裁剪、缩放。
- 左上角 OSD 显示输入尺寸、输出尺寸、页码和模式。
- 图片切换包含淡入淡出、擦除、百叶窗和溶解效果。
- 第 6～11 页有重点文字图层和小老师。
- 底部具有滚动字幕。
- 左下区域有 WAVE 波形；旁边是 128 个实际频率点的填充式频谱，显示约 94 Hz～20 kHz。

## TF 卡素材

- BMP：24-bit、无压缩、小端 BGR，文件名 `1.BMP` 到 `12.BMP`。
- WAV：RIFF/WAVE PCM，48 kHz、16-bit、单声道，文件名 `1.WAV` 到 `12.WAV`。
- 新版朗读原始音频为 48 kHz、24-bit、双声道。由于左右声道电平差异很大且部分内容反相，直接平均会抵消音量；转换时逐文件选择 RMS 更高的原始声道，再舍入为 16-bit，没有做音量缩放、压限、裁掉静音或改变时长。

新版音频总时长为 108.491 秒，逐文件时长和 SHA-256 见 `音频转换清单.json`。
